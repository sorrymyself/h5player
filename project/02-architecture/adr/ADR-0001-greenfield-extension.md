# ADR-0001：Web Extension 采用独立绿地重构

> 状态：Accepted  
> 日期：2026-08-10  
> 决策人：项目维护者  
> 关联：GOV-001、ARCH-003

## Context

现有油猴脚本稳定，但运行时、构建、GM API 和页面全局依赖密集。当前扩展只是复用其构建结果，若直接在原目录上做全量工程化改造，会把新风险带回油猴用户，并使回滚和归因困难。

## Decision

Web Extension 在独立源码边界内进行绿地重构；Legacy 油猴实现继续独立构建、测试和发布。初期不共享运行时源码，只共享经过审查的行为规格、脱敏 fixture 和必要的静态资源。

## Drivers

- 保护现有油猴用户和发布链路。
- 利用 Web Extension 无用户的窗口重建工程体系。
- 允许新架构采用 TypeScript、严格契约和不同构建入口。
- 保持新旧产品可独立回滚。

## Alternatives considered

1. **直接把 Legacy 迁移到 TypeScript**：短期复用高，但会触碰大量隐式状态和站点特例，回归面不可控，否决。
2. **继续包装注入产物**：迁移成本最低，但不能解决权限、测试、类型和模块边界，否决为长期方案。
3. **一次性重写所有功能**：结构清晰但交付周期长、无法逐步验证，否决。

## Consequences

正面：新扩展可拥有清晰架构、独立 CI 和发布；负面：短期会维护两套实现，需维护功能对照矩阵和数据导入工具。

## Follow-ups

- Phase 0 建立 Legacy 行为基线和差分 fixture。
- Beta 后根据代码重复、缺陷率和维护成本评估共享包。
- 任何共享抽取必须新增 ADR，不得以“顺手复用”绕过边界。
