## 1. 摘要

H5Player Web Extension 默认不收集或发送遥测，不提供用户账号、云端同步、广告画像或远程规则服务。扩展处理的数据保存在
用户浏览器本地，除浏览器/商店自身提供的同步、备份或崩溃机制外，项目方没有后端接收这些数据。

本页是仓库事实源；正式商店提交前必须发布到稳定公开 URL，并确认公开版本与目标候选 commit 一致。

## 3. 明确不做的处理

- 不把完整页面 URL、媒体源、页面标题、账号标识或观看内容发送给项目方。
- 不使用 Google Analytics、广告 SDK、远程 feature flag、远程 selector、推荐服务或崩溃上报后端。
- 不出售、出租或共享用户数据，不做跨站画像或自动化决策。
- 不代理媒体、不修改 CORS、不解密 DRM，不绕过登录、付费、地域或访问控制。
- 不从 CDN 或远程地址加载生产 JavaScript/CSS。

## 4. 权限披露

### `storage`

用于本地设置、Schema migration、备份、诊断元数据和用户明确开启的进度。替代方案是每次打开页面重新配置，无法满足可靠性。
当前实现只使用本地 authority；Preview 不启用跨设备 `storage.sync`。

### `activeTab`

用于用户主动打开扩展/执行操作时访问当前标签页。它不授予后台永久浏览所有网站的能力，也不替代用户选择的 host permission。

### `scripting`

在已授权 origin 动态注册和启动扩展包内固定的 content/page-main 脚本。脚本文本不来自网络，参数不允许任意代码或权限名。

### optional `<all_urls>`

manifest 声明可选全站模式，但默认 required host access 为 0。用户可只授权当前 origin，也可主动选择所有站点；拒绝后扩展保持
未连接状态，撤销后立即注销运行时脚本并停止该站点能力。商店提交前必须用 headed 原生权限 UI 验证提示、焦点、接受、拒绝和撤销。

跨源 iframe 只有在其自身 origin 也被浏览器授权时才运行扩展 runtime。扩展不提供能够绕过 host permission 的“跨域控制”开关；frame 协调只在已授权 runtime 之间按真实 tab/frame sender 和 typed command allowlist 进行。只授权顶层站点时，未获授权的第三方 iframe 保持不可控。

## 5. 安全与第三方依赖

- 页面 MAIN world 输入视为不可信；扩展权限由 isolated/background sender policy 复核。
- 设置有严格 Schema、大小/范围限制、checksum backup 与逐版迁移；诊断有容量和脱敏限制。
- 候选包生成 SPDX SBOM、运行时许可证清单、lockfile hash、artifact hash 和 unsigned provenance。
- 运行时依赖及许可证以目标 bundle 的 `sbom.spdx.json` / `third-party-licenses.txt` 为准；浏览器和商店自身的数据处理受其政策约束。

## 6. 用户控制

用户可以：

- 不授予任何站点访问，仅查看扩展界面；
- 按 origin 授权、拒绝或撤销，或撤销 all-sites；
- 关闭并清除进度，重置站点/全局设置，清除诊断；
- 在导出前预览诊断摘要；
- 卸载扩展并由浏览器清除扩展本地数据。

数据损坏时优先读取最近备份，不静默覆盖未来 Schema；任何回滚不得要求修改 Legacy 油猴脚本。

本声明、商店文案和 opt-in UI，并完成 Beta 审查。重大变化不得仅通过静默更新生效。

读取或删除用户设备上的本地扩展数据；清除操作由用户在扩展/浏览器中执行。
